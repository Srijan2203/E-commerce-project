# E-Commerce Data Analysis -

A data analysis project built using **PostgreSQL and Power BI** to explore e-commerce sales, orders, customers, delivery performance, and product categories.

# Tools Used:

* PostgreSQL
* SQL
* Power BI
* GitHub

# What I Did:

* Imported and explored the dataset in PostgreSQL
* Performed data cleaning and analysis using SQL
* Created queries to analyze orders, revenue, customers, and categories
* Built an interactive executive dashboard in Power BI
* Used KPIs and visualizations to identify important trends and patterns

# Some Dashboard KPIs:

* Revenue: 14.21M
* Total Orders: 98.67K
* Total Customers: 95.42K
* Average Order Value: 144.01
* On-Time Delivery: 93.23%
* Average Rating: 4.03
* YoY Growth: 2.53%

# Key Insights

* Health & Beauty generated the highest revenue among the categories shown, followed by Watches & Gifts** and **Bed, Bath & Table.
* Around 97.84% of orders were delivered, showing a high overall order fulfillment rate.
* Order activity varied significantly across months, with higher activity during the earlier period of the dataset.
